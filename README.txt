# John Johnston — online digital business card

This is a static website ready for free hosting. It includes:
- `index.html`: mobile-friendly business card
- `john-johnston.vcf`: downloadable contact file

## Publish free with GitHub Pages
1. Sign in to GitHub or create a free account.
2. Create a new **public** repository, for example `john-johnston-card`.
3. Upload `index.html` and `john-johnston.vcf` to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Once published, GitHub shows the public website URL, typically:
   `https://YOUR-USERNAME.github.io/john-johnston-card/`

## Make the final QR code
The QR code must encode the final public URL above. Replace `YOUR-USERNAME` with your GitHub username and use the full published URL (including trailing slash). Do not use a QR code pointing to a preview or local file.
